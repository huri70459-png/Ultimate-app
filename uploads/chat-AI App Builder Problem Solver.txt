# 🛡️ VeriFlow — The AI Execution Integrity Platform

As a dev who ships AI apps end-to-end, I'd stop fighting these symptoms individually and build **one middleware layer** that sits between my prompts and my production output. I'd call it **VeriFlow**.

---

## 🎯 The Core Idea

VeriFlow is a **single orchestration app** that wraps every AI call in a pipeline of *verification gates*. Instead of trusting the LLM blindly, every step is intercepted, validated, grounded, and traced.

Think of it as **"CI/CD for AI reasoning"** — every execution has to pass quality checks before it reaches the user.

---

## 🏗️ Architecture (5 Layers)

```
┌─────────────────────────────────────────────┐
│  1. INTENT LAYER      → Parses & classifies │
│  2. GROUNDING LAYER   → Retrieves facts     │
│  3. EXECUTION LAYER   → Runs with budget    │
│  4. VALIDATION LAYER  → Self-checks output  │
│  5. TRACE LAYER       → Logs everything     │
└─────────────────────────────────────────────┘
```

---

## 🔧 How It Solves Each Problem

| Problem | VeriFlow Solution |
|---|---|
| **Hallucination** | **Grounding Layer** — Every factual claim is cross-checked against a vector DB + knowledge graph. Unverifiable claims get flagged or rewritten. |
| **Token execution** | **Execution Layer** — Token budgets per task, dynamic prompt compression, and a "token ledger" that stops runaway chains before they blow up costs. |
| **Drift** | **Trace Layer** — Continuous eval against a golden dataset. Alerts when output distribution shifts > threshold from baseline. |
| **Context execution** | **Intent Layer** — Smart context router that injects only *relevant* history (semantic chunking + relevance scoring), not the whole chat. |
| **No grounding** | **Grounding Layer** — Mandatory RAG step with citation enforcement. Output must include source refs or it fails validation. |
| **Low accuracy** | **Validation Layer** — Multi-agent self-critique: a "critic" model reviews the output against the original prompt before release. |
| **Low quality adherence** | **Validation Layer** — Rubric-based scoring (clarity, tone, completeness, safety). Below threshold → auto-retry with refined prompt. |

---

## ⚙️ Key Features

1. **Prompt Contracts** — Every task has a schema (input, expected output format, grounding sources, token budget). No contract = no execution.
2. **Citation-forced generation** — Model must emit `[[source:id]]` tags; post-processor strips invalid ones.
3. **Self-critique loop** — Output → Critic agent → Pass/Fail → Retry (max 2x) or escalate to human.
4. **Token Ledger Dashboard** — Real-time cost/quality/latency per task.
5. **Drift Monitor** — Embedding-distance tracking against baseline; auto-alerts.
6. **Replay & Debug** — Every execution is a traceable DAG. You can replay any run with the exact same context.
7. **Quality Gates** — Configurable rubrics per use case (e.g., "customer support" vs "code generation").

## 🧰 Tech Stack

- **Orchestration:** LangGraph / custom state machine
- **Vector DB:** Qdrant or Weaviate (for grounding)
- **Knowledge Graph:** Neo4j (for fact verification)

- **Tracing:** Langfuse or Phoenix (open-source)
- **Guardrails:** NeMo Guardrails or Guardrails AI

## 🧠 Philosophy: The Real Difference

**VeriFlow's thesis:** "AI lies at the moment of execution → verify every output."

**Project Brain's thesis:** "AI has no model of reality → give it one that persists."

These are not the same problem.

VeriFlow treats AI as a **function** — input → output → validate.
Project Brain treats AI as a **worker** — it needs a job, a map, a history, and a boss.

For software engineering, the second thesis is correct. Code isn't a one-shot answer. It's a living artifact that accumulates decisions, bugs, and conventions over months. A per-request verifier can't catch drift that happens across 400 sessions.

### `brain/config.py`

```python
"""Configuration and path management."""
from __future__ import annotations
import os
from pathlib import Path
from dataclasses import dataclass, field

BRAIN_DIR_NAME = ".brain"

@dataclass
class Config:
    project_root: Path
    brain_dir: Path = field(init=False)
    db_path: Path = field(init=False)
    index_path: Path = field(init=False)
    trace_path: Path = field(init=False)
    openai_model: str = "gpt-4o-mini"
    critic_model: str = "gpt-4o-mini"
    embedding_model: str = "text-embedding-3-small"
    embedding_dim: int = 1536
    max_tokens_per_task: int = 20_000
    max_retries: int = 2
    daily_budget_usd: float = 10.0

    def __post_init__(self) -> None:
        self.brain_dir = self.project_root / BRAIN_DIR_NAME
        self.db_path = self.brain_dir / "brain.sqlite"
        self.index_path = self.brain_dir / "vectors.faiss"
        self.trace_path = self.brain_dir / "traces.jsonl"
        self.brain_dir.mkdir(parents=True, exist_ok=True)

    @classmethod
    def discover(cls, start: Path | None = None) -> "Config":
        """Walk up from `start` to find an existing .brain dir, else use cwd."""
        start = start or Path.cwd()
        cur = start.resolve()
        while True:
            candidate = cur / BRAIN_DIR_NAME
            if candidate.is_dir():
                return cls(project_root=cur)
            parent = cur.parent
            if parent == cur:
                break
            cur = parent
        return cls(project_root=start.resolve())

def get_openai_key() -> str:
    key = os.environ.get("OPENAI_API_KEY")
    if not key:
        raise RuntimeError("OPENAI_API_KEY not set")
    return key
```

### `brain/models.py`

```python
"""Core data models — all persistent state flows through these."""
from __future__ import annotations
from datetime import datetime
from enum import Enum
from typing import Any
from pydantic import BaseModel, Field

def _now() -> str:
    return datetime.utcnow().isoformat(timespec="seconds") + "Z"

class TaskKind(str, Enum):
    CODE_CHANGE = "code_change"
    QUESTION = "question"
    DEBUG = "debug"
    EXPLAIN = "explain"
    PLAN = "plan"

class Verdict(str, Enum):
    PASS = "pass"
    FAIL = "fail"
    UNVERIFIED = "unverified"

class ProjectMeta(BaseModel):
    name: str
    stack: str
    goal: str = ""
    critical_rules: list[str] = Field(default_factory=list)
    created_at: str = Field(default_factory=_now)

class Task(BaseModel):
    id: str
    request: str
    kind: TaskKind

class Storage:
    def __init__(self, cfg: Config) -> None:
        self.cfg = cfg
        self._local = threading.local()
        self._init_db()

    # --- sqlite connection per thread ---
    def _conn(self) -> sqlite3.Connection:
        conn = getattr(self._local, "conn", None)
        if conn is None:
            conn = sqlite3.connect(str(self.cfg.db_path))
            conn.row_factory = sqlite3.Row
            conn.execute("PRAGMA journal_mode=WAL")
            conn.execute("PRAGMA foreign_keys=ON")
            self._local.conn = conn
        return conn

    @contextmanager
    def tx(self) -> Iterator[sqlite3.Connection]:
        conn = self._conn()
        try:
            yield conn
            conn.commit()
        except Exception:
            conn.rollback()
            raise

    def _init_db(self) -> None:
        with self.tx() as c:
            c.executescript("""
                CREATE TABLE IF NOT EXISTS project_meta (
                    key TEXT PRIMARY KEY, value TEXT NOT NULL

                    id TEXT PRIMARY KEY,
                    request TEXT NOT NULL,
                    kind TEXT NOT NULL,

class VectorIndex:
    """Thin wrapper over FAISS for similarity search."""

    def __init__(self, cfg: Config) -> None:
        self.cfg = cfg
        self._ids: list[str] = []
        self._index = None
        self._load()

    def _load(self) -> None:
        import faiss
        if self.cfg.index_path.exists():
            self._index = faiss.read_index(str(self.cfg.index_path))
            ids_path = self.cfg.index_path.with_suffix(".ids.json")
            if ids_path.exists():
                self._ids = json.loads(ids_path.read_text())
        else:
            self._index = faiss.IndexFlatIP(cfg.embedding_dim)

    def _save(self) -> None:
        import faiss
        faiss.write_index(self._index, str(self.cfg.index_path))
        self.cfg.index_path.with_suffix(".ids.json").write_text(
            json.dumps(self._ids)
        )

    def add(self, ids: list[str], vectors: np.ndarray) -> None:
        import faiss
        norms = np.linalg.norm(vectors, axis=1, keepdims=True)
        norms[norms == 0] = 1.0
        normed = (vectors / norms).astype("float32")
        self._index.add(normed)
        self._ids.extend(ids)
        self._save()

    def search(self, q: np.ndarray, k: int = 5) -> list[tuple[str, float]]:
        if self._index.ntotal == 0:
            return []
        qn = q.reshape(1, -1).astype("float32")
        norm = np.linalg.norm(qn)
        if norm > 0:
            qn = qn / norm
        scores, idxs = self._index.search(qn, min(k, self._index.ntotal))
        results = []
        for score, idx in zip(scores[0], idxs[0]):
            if idx < 0 or idx >= len(self._ids):
                continue
            results.append((self._ids[idx], float(score)))
        return results

    @property
    def size(self) -> int:
        return self._index.ntotal

"""LLM abstraction — thin wrapper over OpenAI with token tracking."""
from __future__ import annotations
import time
from dataclasses import dataclass
from openai import OpenAI

from .config import Config, get_openai_key

@dataclass
class LLMResponse:
    content: str
    tokens_in: int
    tokens_out: int
    cost_usd: float
    latency_ms: int

# Pricing per 1M tokens (approx, update as needed)
_PRICING = {
    "gpt-4o":        (2.50, 10.00),
    "gpt-4o-mini":   (0.15, 0.60),
    "gpt-4.1":       (2.00, 8.00),
    "gpt-4.1-mini":  (0.40, 1.60),
}

class LLM:
    def __init__(self, cfg: Config) -> None:
        self.cfg = cfg
        self.client = OpenAI(api_key=get_openai_key())

    def complete(
        self,
        messages: list[dict],
        model: str | None = None,
        temperature: float = 0.2,
        max_tokens: int = 2048,
        response_format: dict | None = None,
    ) -> LLMResponse:
        model = model or self.cfg.openai_model
        kwargs: dict = dict(
            model=model,
            messages=messages,
            temperature=temperature,
            max_tokens=max_tokens,
        )
        if response_format:
            kwargs["response_format"] = response_format

        t0 = time.perf_counter()
        resp = self.client.chat.completions.create(**kwargs)
        latency = int((time.perf_counter() - t0) * 1000)

        content = resp.choices[0].message.content or ""
        usage = resp.usage
        tin = usage.prompt_tokens if usage else 0
        tout = usage.completion_tokens if usage else 0
        cost = self._cost(model, tin, tout)

        return LLMResponse(
            content=content,
            tokens_in=tin, tokens_out=tout,
            cost_usd=cost, latency_ms=latency,
        )

    def embed(self, texts: list[str], model: str | None = None) -> list[list[float]]:
        model = model or self.cfg.embedding_model
        resp = self.client.embeddings.create(model=model, input=texts)
        return [d.embedding for d in resp.data]

    @staticmethod
    def _cost(model: str, tin: int, tout: int) -> float:
        pin, pout = _PRICING.get(model, (0.0, 0.0))
        return (tin * pin + tout * pout) / 1_000_000

### `brain/modules/context_engine.py`

```python
"""Context Engine — semantic retrieval over file digests + decisions."""
from __future__ import annotations
import os
import re
from pathlib import Path

from ..config import Config
from ..storage import Storage, VectorIndex
from ..embeddings import Embedder
from ..models import FileDigest

IGNORE_DIRS = {
    ".brain", ".git", "node_modules", "__pycache__", ".venv", "venv",
    "dist", "build", ".next", ".cache",
}
TEXT_EXTS = {
    ".py", ".js", ".ts", ".tsx", ".jsx", ".json", ".yaml", ".yml",
    ".md", ".txt", ".html", ".css", ".scss", ".sql", ".toml", ".sh",
}
MAX_FILE_BYTES = 200_000

class ContextEngine:
    def __init__(
        self, cfg: Config, storage: Storage,
        index: VectorIndex, embedder: Embedder,
    ) -> None:
        self.cfg = cfg
        self.storage = storage
        self.index = index
        self.embedder = embedder

    # --- indexing ---
    def index_project(self) -> int:
        """Walk project, summarize each text file, embed summaries."""
        root = self.cfg.project_root
        digests: list[FileDigest] = []
        for dirpath, dirnames, filenames in os.walk(root):
            dirnames[:] = [d for d in dirnames if d not in IGNORE_DIRS]
            for fn in filenames:
                p = Path(dirpath) / fn
                if p.suffix.lower() not in TEXT_EXTS:
                    continue
                try:
                    size = p.stat().st_size
                except OSError:
                    continue
                if size > MAX_FILE_BYTES or size == 0:
                    continue
                rel = p.relative_to(root).as_posix()
                try:
                    text = p.read_text(encoding="utf-8", errors="ignore")
                except OSError:
                    continue
                summary = self._summarize(rel, text)
                symbols = self._extract_symbols(rel, text)
                digests.append(FileDigest(
                    path=rel, summary=summary, symbols=symbols,
                ))
        if not digests:
            return 0
        summaries = [
            f"{d.path}\n{d.summary}\nSymbols: {', '.join(d.symbols[:20])}"
            for d in digests
        ]
        vecs = self.embedder.embed_many(summaries)
        ids = [f"file:{d.path}" for d in digests]
        self.index.add(ids, vecs)
        for d in digests:
            self.storage.save_file_digest(d)
        return len(digests)

    def _summarize(self, path: str, text: str) -> str:
        """Cheap heuristic summary: first non-blank 12 lines + docstring if present."""
        lines = text.splitlines()
        head = []
        for ln in lines:
            s = ln.strip()
            if not s:
                continue
            head.append(s)
            if len(head) >= 12:
                break
        return " | ".join(head)

    _PY_FUNC = re.compile(r"^\s*(?:async\s+)?def\s+(\w+)", re.M)
    _PY_CLASS = re.compile(r"^\s*class\s+(\w+)", re.M)
    _JS_FUNC = re.compile(r"(?:function\s+(\w+)|(?:const|let|var)\s+(\w+)\s*=\s*(?:async\s+)?\()", re.M)

    def _extract_symbols(self, path: str, text: str) -> list[str]:
        symbols: list[str] = []
        if path.endswith(".py"):
            symbols.extend(self._PY_CLASS.findall(text))
            symbols.extend(self._PY_FUNC.findall(text))
        elif path.endswith((".js", ".ts", ".tsx", ".jsx")):
            for m in self._JS_FUNC.findall(text):
                symbols.append(m[0] or m[1])
        return symbols[:50]

    # --- retrieval ---
    def retrieve(self, query: str, k: int = 8) -> list[dict]:
        qvec = self.embedder.embed_one(query)
        hits = self.index.search(qvec, k=k)
        results = []
        digests = {f"file:{d.path}": d for d in self.storage.all_file_digests()}
        for id_, score in hits:
            if not id_.startswith("file:"):
                continue
            d = digests.get(id_)
            if not d:
                continue
            results.append({
                "path": d.path,
                "summary": d.summary,
                "symbols": d.symbols,
                "score": score,
            })
        return results

    def build_context(self, query: str, k: int = 8) -> str:
        hits = self.retrieve(query, k=k)
        if not hits:
            return "(no relevant files found in index)"
        parts = []
        for h in hits:
            syms = ", ".join(h["symbols"][:10]) or "—"
            parts.append(
                f"--- {h['path']} (score={h['score']:.2f}) ---\n"
                f"Symbols: {syms}\n"
                f"Summary: {h['summary']}"
            )
        return "\n\n".join(parts)
```

"""Failure Memory — never retry a failed approach."""
from __future__ import annotations
import uuid
import numpy as np

from ..config import Config
from ..storage import Storage, VectorIndex
from ..embeddings import Embedder
from ..models import FailureRecord

class FailureMemory:
    def __init__(
        self, cfg: Config, storage: Storage,
        index: VectorIndex, embedder: Embedder,
    ) -> None:
        self.cfg = cfg
        self.storage = storage
        self.index = index
        self.embedder = embedder

    def record(
        self, task_request: str, attempt_summary: str, failure_reason: str,
    ) -> FailureRecord:
        text = f"{task_request}\n{attempt_summary}\n{failure_reason}"
        vec = self.embedder.embed_one(text)
        rec = FailureRecord(
            id=uuid.uuid4().hex[:12],
            task_request=task_request,
            attempt_summary=attempt_summary,
            failure_reason=failure_reason,
            embedding=vec.tolist(),
        )
        self.storage.save_failure(rec)
        self.index.add([f"fail:{rec.id}"], vec.reshape(1, -1))
        return rec

    def lookup(self, query: str, k: int = 3, threshold: float = 0.80
               ) -> list[tuple[FailureRecord, float]]:
        qvec = self.embedder.embed_one(query)
        hits = self.index.search(qvec, k=k * 2)
        records = {f"fail:{r.id}": r for r in self.storage.all_failures()}
        out: list[tuple[FailureRecord, float]] = []
        for id_, score in hits:
            if not id_.startswith("fail:"):
                continue
            r = records.get(id_)
            if r and score >= threshold:
                out.append((r, score))
                if len(out) >= k:
                    break
        return out

    def warning_block(self, query: str) -> str:
        hits = self.lookup(query)
        if not hits:
            return ""
        lines = ["⚠️  SIMILAR PAST FAILURES — DO NOT REPEAT THESE APPROACHES:"]
        for rec, score in hits:
            lines.append(
                f"  • (sim={score:.2f}) Request: {rec.task_request[:120]}\n"
                f"    Attempt: {rec.attempt_summary[:200]}\n"
                f"    Failed because: {rec.failure_reason[:200]}"
            )
        return "\n".join(lines)

```python
"""Ground Truth Engine — verify claims against the actual codebase."""
from __future__ import annotations
import os
import re
import sqlite3
from pathlib import Path

from ..config import Config
from ..models import Claim, Verdict

class GroundTruth:
    def __init__(self, cfg: Config) -> None:
        self.cfg = cfg

    def verify(self, claims: list[Claim]) -> list[Claim]:
        return [self._verify_one(c) for c in claims]

    def _verify_one(self, c: Claim) -> Claim:
        try:
            if c.kind == "file_exists":
                ok = (self.cfg.project_root / c.target).exists()
                c.verdict = Verdict.PASS if ok else Verdict.FAIL
                c.evidence = f"path={c.target} exists={ok}"
            elif c.kind == "symbol_exists":
                ok = self._symbol_in_codebase(c.target)
                c.verdict = Verdict.PASS if ok else Verdict.FAIL
                c.evidence = f"symbol={c.target} found={ok}"
            elif c.kind == "schema_match":
                ok, msg = self._check_schema(c.target)
                c.verdict = Verdict.PASS if ok else Verdict.FAIL
                c.evidence = msg
            elif c.kind == "path_in_output":
                ok = (self.cfg.project_root / c.target).exists()
                c.verdict = Verdict.PASS if ok else Verdict.FAIL
                c.evidence = f"output references {c.target}, exists={ok}"
            else:
                c.verdict = Verdict.UNVERIFIED
                c.evidence = f"no verifier for kind={c.kind}"
        except Exception as e:
            c.verdict = Verdict.UNVERIFIED
            c.evidence = f"error: {e}"
        return c

    def _symbol_in_codebase(self, symbol: str) -> bool:
        if not re.match(r"^[A-Za-z_][A-Za-z0-9_]*$", symbol):
            return False
        pattern = re.compile(r"\b" + re.escape(symbol) + r"\b")
        for dirpath, dirnames, filenames in os.walk(self.cfg.project_root):
            dirnames[:] = [d for d in dirnames
                           if d not in {".brain", ".git", "node_modules",
                                        "__pycache__", ".venv", "venv"}]
            for fn in filenames:
                p = Path(dirpath) / fn
                if p.suffix.lower() not in {
                    ".py", ".js", ".ts", ".tsx", ".jsx", ".sql",
                }:
                    continue
                try:
                    text = p.read_text(encoding="utf-8", errors="ignore")
                except OSError:
                    continue
                if pattern.search(text):
                    return True
        return False

    def _check_schema(self, spec: str) -> tuple[bool, str]:
        """spec format: 'sqlite:path/to/db.sqlite table:users column:email'"""
        parts = dict(p.split(":", 1) for p in spec.split() if ":" in p)
        db = parts.get("sqlite")
        table = parts.get("table")
        column = parts.get("column")
        if not (db and table):
            return False, "schema spec must include sqlite: and table:"
        db_path = self.cfg.project_root / db
        if not db_path.exists():
            return False, f"db not found: {db}"
        try:
            conn = sqlite3.connect(str(db_path))
            cur = conn.execute(f"PRAGMA table_info({table})")
            cols = {row[1] for row in cur.fetchall()}
            conn.close()
        except sqlite3.Error as e:
            return False, f"sqlite error: {e}"
        if column:
            ok = column in cols
            return ok, f"table={table} column={column} present={ok} cols={sorted(cols)}"
        return True, f"table={table} exists cols={sorted(cols)}"
```

### `brain/modules/quality_engine.py`

```python
"""Quality Engine — heuristic scoring of LLM output."""
from __future__ import annotations
import re

class QualityReport:
    def __init__(self, score: float, issues: list[str]) -> None:
        self.score = score
        self.issues = issues

class QualityEngine:
    """Heuristic scorer — no LLM call, instant feedback."""

    def score(self, output: str, request: str) -> QualityReport:
        issues: list[str] = []
        penalties = 0.0

        if len(output.strip()) < 30:
            issues.append("output suspiciously short")
            penalties += 0.3

        todo_count = len(re.findall(r"\bTODO\b|\bFIXME\b|\bXXX\b", output, re.I))
        if todo_count > 0:
            issues.append(f"contains {todo_count} TODO/FIXME markers")
            penalties += 0.1 * min(todo_count, 3)

        if re.search(r"I('|\s)(don't|do not)\s+know", output, re.I):
            issues.append("contains 'I don't know' hedge")
            penalties += 0.2

        lines = output.splitlines()
        long_lines = sum(1 for ln in lines if len(ln) > 200)
        if long_lines > 3:
            issues.append(f"{long_lines} lines exceed 200 chars")
            penalties += 0.05 * long_lines

        if not any(re.search(re.escape(w), output, re.I)
                   for w in request.split()[:5] if len(w) > 4):
            issues.append("output may not address the request")
            penalties += 0.15

        if output.count("```") % 2 != 0:
            issues.append("unbalanced code fences")
            penalties += 0.1

        score = max(0.0, min(1.0, 1.0 - penalties))
        return QualityReport(score=score, issues=issues)
```

"""Execution — call the LLM with budget and grounding."""
from __future__ import annotations
import json
import re
from ..config import Config
from ..llm import LLM, LLMResponse
from ..models import Claim

CITATION_RE = re.compile(r"\[\[source:([^\]]+)\]\]")

class ExecutionResult:
    def __init__(
        self,
        response: LLMResponse,
        claims: list[Claim],
        citations: list[str],
        raw_output: str,
    ) -> None:
        self.response = response
        self.claims = claims
        self.citations = citations
        self.raw_output = raw_output

class Executor:
    def __init__(self, cfg: Config, llm: LLM) -> None:
        self.cfg = cfg
        self.llm = llm

    def run(
        self,
        request: str,
        grounding_section: str,
        extra_instructions: str = "",
    ) -> ExecutionResult:
        sys = (
            "You are a careful software engineer working inside a real codebase.\n"
            "RULES:\n"
            "1. Cite every file you reference as [[source:path/to/file]].\n"
            "2. For every factual claim, emit a line 'CLAIM:<kind>:<target>:<text>'.\n"
            "   Kinds: file_exists, symbol_exists, schema_match, factual.\n"
            "3. If you are unsure, say so — do not guess.\n"
            "4. Respect all CRITICAL RULES.\n"
            "5. Be concise and concrete.\n"
        )
        if extra_instructions:
            sys += "\n" + extra_instructions
        user = f"{grounding_section}\n\n=== USER REQUEST ===\n{request}"

        resp = self.llm.complete(
            messages=[
                {"role": "system", "content": sys},
                {"role": "user", "content": user},
            ],
            temperature=0.2,
            max_tokens=min(4096, self.cfg.max_tokens_per_task),
        )

        citations = list({m.group(1) for m in CITATION_RE.finditer(resp.content)})
        claims = self._extract_claims(resp.content)

        return ExecutionResult(
            response=resp,
            claims=claims,
            citations=citations,
            raw_output=resp.content,
        )

    def _extract_claims(self, text: str) -> list[Claim]:
        claims: list[Claim] = []
        for line in text.splitlines():
            if not line.startswith("CLAIM:"):
                continue
            parts = line.split(":", 3)
            if len(parts) < 4:
                continue
            _, kind, target, claim_text = parts
            claims.append(Claim(
                text=claim_text.strip(),
                kind=kind.strip(),
                target=target.strip(),
            ))
        return claims

### `brain/veriflow/validation.py`

```python
"""Validation — self-critic + quality scoring."""
from __future__ import annotations
import json
from ..llm import LLM
from ..models import Claim, Verdict
from ..modules.ground_truth import GroundTruth
from ..modules.quality_engine import QualityEngine

class ValidationResult:
    def __init__(
        self,
        verdict: Verdict,
        critic_reason: str,
        claims: list[Claim],
        quality_score: float,
        quality_issues: list[str],
    ) -> None:
        self.verdict = verdict
        self.critic_reason = critic_reason
        self.claims = claims
        self.quality_score = quality_score
        self.quality_issues = quality_issues

class Validator:
    def __init__(
        self, llm: LLM, ground_truth: GroundTruth, quality: QualityEngine,
    ) -> None:
        self.llm = llm
        self.ground_truth = ground_truth
        self.quality = quality

    def validate(
        self, request: str, output: str, claims: list[Claim],
    ) -> ValidationResult:
        # 1. verify factual claims against the codebase
        verified_claims = self.ground_truth.verify(claims)
        failed = [c for c in verified_claims if c.verdict == Verdict.FAIL]

        # 2. heuristic quality
        qr = self.quality.score(output, request)

        # 3. self-critic LLM call
        critic_reason = ""
        critic_verdict = Verdict.PASS
        if failed or qr.score < 0.6:
            critic_verdict, critic_reason = self._critic(request, output, verified_claims, qr)

        # overall verdict
        if any(c.verdict == Verdict.FAIL for c in verified_claims):
            verdict = Verdict.FAIL
        elif qr.score < 0.5:
            verdict = Verdict.FAIL
        elif critic_verdict == Verdict.FAIL:
            verdict = Verdict.FAIL
        else:
            verdict = Verdict.PASS

        return ValidationResult(
            verdict=verdict,
            critic_reason=critic_reason,
            claims=verified_claims,
            quality_score=qr.score,
            quality_issues=qr.issues,
        )

    def _critic(
        self, request: str, output: str,
        claims: list[Claim], qr,
    ) -> tuple[Verdict, str]:
        claim_block = "\n".join(
            f"- [{c.verdict.value}] {c.text} (target={c.target})"
            for c in claims
        ) or "(no claims)"
        sys = (
            "You are a strict code reviewer. Decide if the output safely and "
            "correctly addresses the request. Respond with JSON: "
            '{"verdict": "pass"|"fail", "reason": str}'
        )
        user = (
            f"REQUEST: {request}\n\n"
            f"OUTPUT:\n{output[:3000]}\n\n"
            f"CLAIMS:\n{claim_block}\n\n"
            f"QUALITY: score={qr.score:.2f} issues={qr.issues}"
        )
        resp = self.llm.complete(
            messages=[
                {"role": "system", "content": sys},
                {"role": "user", "content": user},
            ],
            temperature=0.0,
            max_tokens=300,
            response_format={"type": "json_object"},
        )
        try:
            data = json.loads(resp.content)
            v = Verdict.FAIL if data.get("verdict") == "fail" else Verdict.PASS
            return v, str(data.get("reason", ""))
        except json.JSONDecodeError:
            return Verdict.UNVERIFIED, "critic parse failure"

### `brain/veriflow/pipeline.py`

```python
"""VeriFlow pipeline — the runtime kernel."""
from __future__ import annotations
import uuid
from ..config import Config
from ..storage import Storage
from ..llm import LLM
from ..models import (
    Task, TaskKind, ExecutionResult as ExecModel, Verdict, FailureRecord,
)
from .intent import IntentClassifier
from .grounding import Grounding
from .execution import Executor
from .validation import Validator
from .trace import Tracer
from ..modules.reality_graph import RealityGraph
from ..modules.context_engine import ContextEngine
from ..modules.failure_memory import FailureMemory
from ..modules.ground_truth import GroundTruth
from ..modules.token_governor import TokenGovernor, BudgetExceeded
from ..modules.change_governor import ChangeGovernor
from ..modules.quality_engine import QualityEngine

class PipelineResult:
    def __init__(self, execution: ExecModel, passed: bool, failure_note: str = "") -> None:
        self.execution = execution
        self.passed = passed
        self.failure_note = failure_note

class Pipeline:
    def __init__(
        self,
        cfg: Config,
        storage: Storage,
        llm: LLM,
        reality: RealityGraph,
        context: ContextEngine,
        failures: FailureMemory,
        governor: TokenGovernor,
        change_gov: ChangeGovernor,
    ) -> None:
        self.cfg = cfg
        self.storage = storage
        self.llm = llm
        self.reality = reality
        self.context = context
        self.failures = failures
        self.governor = governor
        self.change_gov = change_gov

        self.intent = IntentClassifier(llm)
        self.grounding = Grounding(reality, context, failures)
        self.executor = Executor(cfg, llm)
        self.validator = Validator(llm, GroundTruth(cfg), QualityEngine())
        self.tracer = Tracer(storage)

    def run(self, request: str) -> PipelineResult:
        task_id = uuid.uuid4().hex[:12]
        self.tracer.log(task_id, "start", {"request": request})

        # 0. budget check
        try:
            self.governor.check()
        except BudgetExceeded as e:
            return self._abort(task_id, request, str(e))

        # 1. intent
        intent = self.intent.classify(request)
        task = Task(id=task_id, request=request, kind=intent.kind)
        self.storage.save_task(task)
        self.tracer.log(task_id, "intent", {
            "kind": intent.kind.value,
            "entities": intent.entities,
            "summary": intent.summary,
        })

        # 2. change governor (for code changes)
        if intent.kind == TaskKind.CODE_CHANGE:
            scope = self.change_gov.evaluate(request, self.reality.rules())
            self.tracer.log(task_id, "scope", {
                "approved": scope.approved,
                "reason": scope.reason,
                "files": scope.scope_files,
            })
            if not scope.approved:
                return self._abort(task_id, request, f"Scope rejected: {scope.reason}")

        # 3. grounding
        bundle = self.grounding.build(request)
        grounding_section = bundle.as_prompt_section()
        self.tracer.log(task_id, "grounding", {
            "has_failure_warning": bool(bundle.failure_warning),
            "decisions": len(bundle.decisions),
        })

        # 4. execute + validate with retry
        retries = 0
        extra = ""
        last_exec = None
        while retries <= self.cfg.max_retries:
            self.tracer.log(task_id, "execute", {"attempt": retries + 1})
            exec_result = self.executor.run(
                request, grounding_section, extra_instructions=extra,
            )
            validation = self.validator.validate(
                request, exec_result.raw_output, exec_result.claims,
            )
            last_exec = ExecModel(
                task_id=task_id,
                output=exec_result.raw_output,
                citations=exec_result.citations,
                claims=validation.claims,
                tokens_in=exec_result.response.tokens_in,
                tokens_out=exec_result.response.tokens_out,
                cost_usd=exec_result.response.cost_usd,
                latency_ms=exec_result.response.latency_ms,
                verdict=validation.verdict,
                retries=retries,
                quality_score=validation.quality_score,
            )
            if validation.verdict == Verdict.PASS:
                break
            retries += 1
            extra = (
                "PREVIOUS ATTEMPT FAILED. Fix these issues:\n"
                f"- Critic: {validation.critic_reason}\n"
                f"- Quality issues: {validation.quality_issues}\n"
                f"- Failed claims: "
                f"{[c.text for c in validation.claims if c.verdict == Verdict.FAIL]}"
            )

        # 5. persist
        self.storage.save_execution(last_exec)
        self.tracer.log(task_id, "done", {
            "verdict": last_exec.verdict,
            "retries": last_exec.retries,
            "quality": last_exec.quality_score,
            "cost": last_exec.cost_usd,
        })

        if last_exec.verdict != Verdict.PASS:
            self.failures.record(
                task_request=request,
                attempt_summary=last_exec.output[:400],
                failure_reason=(
                    f"verdict={last_exec.verdict} quality={last_exec.quality_score:.2f}"
                ),
            )
            return PipelineResult(
                last_exec, passed=False,
                failure_note=f"verdict={last_exec.verdict}",
            )

        return PipelineResult(last_exec, passed=True)

    def _abort(self, task_id: str, request: str, reason: str) -> PipelineResult:
        e = ExecModel(
            task_id=task_id, output=f"[ABORTED] {reason}",
            verdict=Verdict.FAIL,
        )
        self.storage.save_execution(e)
        self.tracer.log(task_id, "aborted", {"reason": reason})
        return PipelineResult(e, passed=False, failure_note=reason)
```

                r.created_at[11:19],
                f"[{v_color}]{r.verdict}[/{v_color}]",
                f"{r.quality_score:.2f}",
                str(r.tokens_in + r.tokens_out),
                f"${r.cost_usd:.4f}",
                str(r.retries),
                preview,
            )

        project_name = meta.name if meta else "(uninitialized)"
        header = (
            f"[bold]{project_name}[/bold]"
            + (f" — {meta.stack}" if meta else "")
        )

        self.console.print()
        self.console.print(Panel(header, title="PROJECT BRAIN", border_style="cyan"))
        self.console.print(Panel(health, title="PROJECT HEALTH", border_style="green"))
        self.console.print(Panel(activity, title="AI ACTIVITY", border_style="yellow"))
        self.console.print(Panel(runs, title="RECENT RUNS", border_style="magenta"))

### `brain/cli.py`

```python
"""CLI entry point."""
from __future__ import annotations
import click
from rich.console import Console
from rich.panel import Panel

from .config import Config
from .storage import Storage, VectorIndex
from .llm import LLM
from .embeddings import Embedder
from .modules.reality_graph import RealityGraph
from .modules.context_engine import ContextEngine
from .modules.failure_memory import FailureMemory
from .modules.token_governor import TokenGovernor
from .modules.change_governor import ChangeGovernor
from .veriflow.pipeline import Pipeline
from .dashboard import Dashboard

console = Console()

def _build(cfg: Config):
    storage = Storage(cfg)
    index = VectorIndex(cfg)
    llm = LLM(cfg)
    embedder = Embedder(cfg, llm)
    reality = RealityGraph(cfg, storage)
    context = ContextEngine(cfg, storage, index, embedder)
    failures = FailureMemory(cfg, storage, index, embedder)
    governor = TokenGovernor(cfg, storage)
    change_gov = ChangeGovernor(cfg, llm)
    pipeline = Pipeline(
        cfg, storage, llm, reality, context, failures, governor, change_gov,
    )
    dashboard = Dashboard(cfg, storage, index)
    return {
        "cfg": cfg, "storage": storage, "index": index, "llm": llm,
        "embedder": embedder, "reality": reality, "context": context,
        "failures": failures, "governor": governor, "change_gov": change_gov,
        "pipeline": pipeline, "dashboard": dashboard,
    }

@click.group()
@click.pass_context
def cli(ctx) -> None:
    """Project Brain — AI Operating System for building software."""
    ctx.ensure_object(dict)

@cli.command()
@click.option("--name", required=True, help="Project name")
@click.option("--stack", required=True, help="Tech stack, e.g. 'Python/FastAPI/React'")
@click.option("--goal", default="", help="Project goal")
def init(name: str, stack: str, goal: str) -> None:
    """Initialize a new project brain in the current directory."""
    cfg = Config.discover()
    parts = _build(cfg)
    meta = parts["reality"].init_project(name=name, stack=stack, goal=goal)
    console.print(Panel(
        f"Initialized brain for [bold]{meta.name}[/bold]\n"
        f"Stack: {meta.stack}\n"
        f"Brain dir: {cfg.brain_dir}",
        title="INIT", border_style="green",
    ))

@cli.command()
@click.option("--index/--no-index", default=True,
              help="Re-index project files before running")
def index(index: bool) -> None:
    """(Re)index project files into the vector store."""
    cfg = Config.discover()
    parts = _build(cfg)
    if index:
        n = parts["context"].index_project()
        console.print(f"[green]Indexed {n} files.[/green]")

@cli.command()
@click.argument("request")
@click.option("--no-index", is_flag=True, help="Skip re-indexing")
def run(request: str, no_index: bool) -> None:
    """Run a task through the VeriFlow pipeline."""
    cfg = Config.discover()
    parts = _build(cfg)
    if not no_index:
        parts["context"].index_project()
    console.print(Panel(request, title="REQUEST", border_style="cyan"))
    result = parts["pipeline"].run(request)
    color = "green" if result.passed else "red"
    console.print(Panel(
        result.execution.output,
        title=f"[{color}]RESULT ({result.execution.verdict})[/{color}]",
        border_style=color,
    ))
    console.print(
        f"tokens={result.execution.tokens_in + result.execution.tokens_out} "
        f"cost=${result.execution.cost_usd:.4f} "
        f"retries={result.execution.retries} "
        f"quality={result.execution.quality_score:.2f}"
    )
    if result.execution.citations:
        console.print("[dim]citations:[/dim]")
        for c in result.execution.citations:
            console.print(f"  • {c}")
    if not result.passed:
        console.print(f"[red]Failure note: {result.failure_note}[/red]")

@cli.command()
def status() -> None:
    """Show the project dashboard."""
    cfg = Config.discover()
    parts = _build(cfg)
    parts["dashboard"].render()

@cli.command()
@click.argument("rule")
def rule(rule: str) -> None:
    """Add a critical rule (e.g. 'Never modify auth layer')."""
    cfg = Config.discover()
    parts = _build(cfg)
    parts["reality"].add_rule(rule)
    console.print(f"[green]Added rule:[/green] {rule}")

@cli.command()
@click.argument("title")
@click.argument("rationale")
def decide(title: str, rationale: str) -> None:
    """Record an architectural decision."""
    cfg = Config.discover()
    parts = _build(cfg)
    d = parts["reality"].add_decision(title=title, rationale=rationale, files=[])
    console.print(f"[green]Decision {d.id}:[/green] {title}")

if __name__ == "__main__":
    cli()
```

import os

from brain.config import Config

def test_ground_truth_file_exists():
    with tempfile.TemporaryDirectory() as tmp:
        root = Path(tmp)
        (root / "hello.py").write_text("def greet(): pass\n")
        cfg = Config(project_root=root)
        gt = GroundTruth(cfg)
        c = Claim(text="hello.py exists", kind="file_exists", target="hello.py")
        out = gt.verify([c])[0]
        assert out.verdict == Verdict.PASS

        c2 = Claim(text="missing.py exists", kind="file_exists", target="missing.py")
        out2 = gt.verify([c2])[0]
        assert out2.verdict == Verdict.FAIL

def test_quality_engine_short_output():
    qe = QualityEngine()
    r = qe.score("hi", "please write a long explanation")
    assert r.score < 1.0
    assert any("short" in i for i in r.issues)

def test_quality_engine_clean_output():
    qe = QualityEngine()
    text = "Here is a proper explanation of the login flow that addresses the request."
    r = qe.score(text, "explain the login flow")
    assert r.score >= 0.7

## 🏃 Usage Walkthrough

### 1. Initialize

```bash
cd ~/projects/myapp
brain init --name MyApp --stack "Python/FastAPI/Postgres" --goal "SaaS billing platform"
brain rule "Never modify the payments module without explicit approval"
brain rule "All API routes must have OpenAPI schemas"
brain decide "Use JWT for auth" "Simpler than sessions, stateless, works across services"
```

### 2. Run a task

```bash
brain run "Add CSV export to the /users endpoint"
```

What happens under the hood:
1. **Intent** → classifies as `code_change`
2. **Change Governor** → checks scope, confirms it's just `/users` endpoint
3. **Grounding** → retrieves:
   - Project meta + critical rules
   - 8 most relevant files (users route, models, schemas)
   - Past failures similar to this request
   - Related decisions
4. **Execute** → LLM generates output with `[[source:...]]` citations and `CLAIM:` lines
5. **Validate** → GroundTruth verifies each claim (file exists? symbol exists? schema matches?), QualityEngine scores, self-critic reviews
6. **If FAIL** → retry up to 2× with failure feedback injected
7. **Trace** → every stage logged to `.brain/traces.jsonl`
8. **On final failure** → stored in FailureMemory so next similar request won't repeat it

### 3. Check health

```bash
brain status
```

Shows the dashboard: project health, AI activity, recent runs.
